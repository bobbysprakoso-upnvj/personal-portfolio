# Agent Instructions

## Project

Personal Portfolio Website

## Working Rules

- Read BRIEF.md before proposing implementation.
- Do not start coding immediately.
- Use the Superpowers brainstorming workflow first.
- Inspect the repository before making recommendations.
- Ask clarification questions when requirements are ambiguous.
- Present design alternatives and trade-offs.
- Wait for explicit user approval before generating an implementation plan.
- Use writing-plans after the design is approved.
- Do not implement the plan until explicitly requested.
- Do not add frameworks or dependencies without approval.
- Keep the solution simple and suitable for GitHub Pages.
- Never introduce credentials or secrets.
